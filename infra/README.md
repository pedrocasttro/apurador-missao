# Infraestrutura

Alvo opcional: S3 privado + CloudFront/OAC + ACM + DNS para hospedar apenas o frontend estático e assets próprios. O navegador lê resultados diretamente da CDN do TSE.

Nenhum recurso foi provisionado. Não há worker, API de dados, banco ou bucket de resultados. A publicação estática terá validação de plano e testes de acesso/cache antes de deploy.
